# Unused & Reference Files Archive

This directory contains auxiliary project artifacts, reference documentation, evaluation rubrics, presentation scripts, and planning schedules separated from the primary application code.

---

### File Inventory & Descriptions

| File Name | Format | Purpose / Description |
| :--- | :---: | :--- |
| **`technical_system_audit.md`** | Markdown | Comprehensive 1,358-line technical specification, audit findings, datastore schema, and cryptography reference manual. |
| **`system_presentation_guide.md`** | Markdown | Panel presentation checklist, feature walkthrough, and 4-act live demonstration script for evaluators. |
| **`project_gantt_chart.xlsx`** | Excel | Project management schedule, development milestones, and timeline breakdown. |
| **`special_project_requirements.xlsx`** | Excel | Matrix of special project deliverables (Sentinel Checkpoint, QR Badges, Scanner HUD). |
| **`system_functions_matrix.xlsx`** | Excel | Detailed mapping of all system functions, user clearance permissions, and audit requirements. |

---

*Note: All core application files (backend logic, public frontend portals, active functional specifications, and security audit reports) remain in the root and `/public` directories.*
